## カーソル周辺を、ポータブルに拡大確認。

## 概要

VisualBuddy Lite は、画面上のカーソル周辺を拡大表示し、十字ラインで注目位置を示す Windows 用の軽量ツールです。  
プレゼン、画面共有、細部確認、文字や UI の確認作業に利用できます。

## 主な機能

- カーソル位置を示す十字ラインの常時表示
- `Alt + 無変換` による一時的な拡大レンズ表示
- レンズ表示中の `L` キーによる固定／解除
- レンズと十字ラインの重なりを回避
- タスクトレイ常駐
- ポータブル起動対応
- ライトプロテクトされた USB メモリからの起動に対応
- ホットキーによる十字ラインの切り替えとアプリ終了
- DPI 設定のフォールバック
- ホットキー競合時の通知

## ホットキー

| キー | 動作 |
| --- | --- |
| `Alt + 無変換` | 押している間、拡大レンズを表示 |
| `L` | レンズ表示中に固定／解除 |
| `Alt + Ctrl + J` | 十字ラインの ON／OFF を切り替え |
| `Alt + Ctrl + End` | アプリを終了 |

## 使い方

1. `VisualBuddy Lite v1.0.1.exe` を起動します。
2. 十字ラインがカーソル位置を示します。
3. `Alt + 無変換` を押している間、カーソル周辺のレンズが表示されます。
4. レンズ表示中に `L` を押すと、レンズ表示を固定または解除できます。
5. タスクトレイメニューから終了できます。

## ポータブル仕様

- インストール不要で、EXE 単体で起動できます。
- レジストリ、ユーザーフォルダ、EXE と同じフォルダへ、設定・ログ・一時ファイルを書き込みません。
- ライトプロテクトされた USB メモリからも起動できます。
- USB メモリから起動する場合も、EXE をそのまま起動してください。
- USB メモリからの起動中に起動元ドライブが読み取れなくなった場合は、安全のため自動終了します。
- 詳細は `Documents` フォルダ内の基本仕様書を確認してください。

## English

### Portable magnification for precise cursor-area checks.

## Overview

VisualBuddy Lite is a lightweight Windows tool that shows a magnified view around the cursor and uses crosshair lines to indicate the target position.  
It is useful for presentations, screen sharing, detail checks, and reading small UI elements or text.

## Main Features

- Always-visible crosshair lines indicating the cursor position
- Temporary magnifier activated with `Alt + NonConvert`
- Lock or unlock the lens with `L` while it is visible
- Prevention of overlap between the lens and crosshair lines
- System tray operation
- Portable startup support
- Support for startup from a read-only USB drive
- Hotkeys for toggling the crosshair and exiting the app
- DPI fallback
- Notification when hotkey registration fails

## Hotkeys

| Key | Action |
| --- | --- |
| `Alt + NonConvert` | Show the magnifier while the keys are held down |
| `L` | Lock or unlock the lens while it is visible |
| `Alt + Ctrl + J` | Toggle the crosshair ON or OFF |
| `Alt + Ctrl + End` | Exit the app |

## How to Use

1. Launch `VisualBuddy Lite v1.0.1.exe`.
2. The crosshair lines indicate the cursor position.
3. Hold `Alt + NonConvert` to display the magnifier around the cursor.
4. While the lens is visible, press `L` to lock or unlock it.
5. You can exit the app from the system tray menu.

## Portable Specification

- No installation is required; the EXE can be launched directly.
- The app does not write settings, logs, or temporary files to the registry, user profile, or executable folder.
- The app can be launched from a read-only USB drive.
- To launch it from a USB drive, run the EXE directly.
- When launched from a USB drive, the app exits automatically if the startup drive becomes unavailable.
- See the basic specification document in the `Documents` folder for details.

- [`Documents/割り当てキー一覧.txt`](Documents/割り当てキー一覧.txt)

## Notes

- Hotkey registration can fail if another app already uses the same shortcuts.
- Screen capture can fail in some protected-window, remote-desktop, or mixed-DPI environments.
- Capture exclusion depends on the Windows version and environment.
- Windows Defender SmartScreen or a similar warning may appear after download or on first launch.
